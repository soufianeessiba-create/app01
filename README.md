# app01

This repository now contains a small Progressive Web App (PWA) scaffold built with React + Vite.

Pour développer localement :

1. Installer les dépendances

```bash
npm install
```

2. Lancer le serveur de développement

```bash
npm run dev
```

3. Construire pour la production

```bash
npm run build
npm run preview
```

Notes:
- Le manifeste (manifest.webmanifest) et le service worker (service-worker.js) sont inclus pour supporter l'installation (Add to Home Screen).
- Vous pouvez déployer le dossier `dist/` sur GitHub Pages, Netlify, ou tout autre hébergeur statique.

Aide / prochaines étapes possibles :
- Ajouter une API backend si besoin (Express, Supabase, Firebase...).
- Créer des icônes PNG de différentes tailles et les référencer dans le manifeste pour meilleure compatibilité.
